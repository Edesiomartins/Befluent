# Stack Oficial do BeFluent

## Frontend

- Next.js
- TypeScript
- App Router
- Tailwind CSS
- Interface responsiva para computador, tablet e celular

## Backend

- Python
- FastAPI
- SQLAlchemy
- Alembic
- Pydantic

## Banco de dados

- PostgreSQL

## Inteligência artificial

- OpenRouter
- Um modelo principal
- Um modelo de fallback
- Chaves armazenadas apenas em variáveis de ambiente

## Áudio

- Speech-to-Text com arquitetura modular
- Text-to-Speech com arquitetura modular
- O provedor será definido após testes

## Infraestrutura

- Docker
- Docker Compose
- Coolify
- VPS própria
- HTTPS

## Desenvolvimento

- Cursor como IDE principal
- Git para controle de versão
- Testes locais antes de qualquer deploy

## Segurança

- Aplicação privada
- Sem cadastro público
- Apenas um usuário autorizado inicialmente
- Segredos nunca devem ser expostos no frontend
- Sessão segura usando cookie HTTP-only

## Regras

- Não trocar esta stack sem autorização.
- Não adicionar Redis antes de existir necessidade real.
- Não implementar serviços externos antes da fundação estar testada.
- Toda mudança estrutural deve ser documentada.
