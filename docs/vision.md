# Visão do Fluentia

## Propósito

O Fluentia é um webapp pessoal para aprendizado de idiomas com apoio de inteligência artificial, voz, prática guiada e acompanhamento de progresso.

## Usuário principal

O sistema será criado inicialmente para uso pessoal do proprietário do projeto.

Não haverá cadastro público nesta fase.

## Idiomas iniciais

- Inglês
- Espanhol da Espanha
- Francês
- Japonês
- Mandarim

## Objetivos principais

- Desenvolver conversação.
- Melhorar compreensão auditiva.
- Ampliar vocabulário.
- Reforçar gramática.
- Praticar pronúncia.
- Melhorar leitura e escrita.
- Registrar erros recorrentes.
- Acompanhar progresso.
- Criar revisões personalizadas.
- Adaptar o estudo ao desempenho do usuário.

## Princípios pedagógicos

- Cada idioma deve ter uma estratégia própria.
- As atividades devem ser adequadas ao nível do usuário.
- As correções devem ser claras, respeitosas e úteis.
- O sistema deve explicar os erros, não apenas apontá-los.
- O conteúdo deve priorizar situações reais de comunicação.
- O progresso deve ser baseado em dados compreensíveis.
- O excesso de exercícios deve ser evitado.
- O sistema deve recomendar a próxima atividade com base no desempenho anterior.

## Princípios de experiência

- Interface adulta, limpa e acadêmica.
- Navegação simples.
- Textos da interface em português.
- Boa experiência em computador, tablet e celular.
- Não usar aparência infantil.
- Não sobrecarregar as telas com métricas ou botões.
- Toda funcionalidade deve ter utilidade clara.

## Privacidade

- O Fluentia será uma aplicação privada.
- Apenas o usuário autorizado terá acesso.
- Chaves de serviços externos nunca devem aparecer no frontend.
- Dados de estudo e conversação devem permanecer protegidos.
- O sistema não deve armazenar áudios permanentemente sem necessidade.

## Hospedagem

- Desenvolvimento local no Cursor.
- Testes locais antes da publicação.
- Deploy posterior em VPS própria pelo Coolify.
- Acesso protegido por HTTPS.

## Critério de qualidade

Uma funcionalidade só será considerada concluída quando:

- funcionar corretamente;
- possuir tratamento de erros;
- tiver sido testada;
- estiver documentada;
- apresentar uma experiência simples para o usuário;
- não comprometer a segurança ou a estabilidade do sistema.
